**Judge takeaway:** Persistent teaching plus honest, inspectable memory boundary.

**Narration:** “In a new session, Jules writes an ambiguous joke. Keyword toxicity might call this mild. TEND remembers Kai's earlier request, so context changes the judgment. It recommends a private, gentle reminder—no ban, no timeout—and explains exactly which memory mattered.”

## 1:02–1:18 — Human authority

**Screen:** Show the draft and click “Approve & schedule follow-up.”

**Narration:** “Contacting a member requires explicit approval. In demo mode the delivery is recorded locally and clearly labeled. Approval creates a persisted due job, not an animation.”

**Judge takeaway:** Working safety gate and trustworthy demo language.

**Screen:** Countdown. Point to persisted state, attempt count, and live worker indicator. Do not click.

**Narration:** “Now we wait. Without another creator prompt, the worker atomically claims the due job and consumes a deterministic seeded observation. The evidence is simulated; the scheduling, claim, and persisted state transition are real.”

## 1:40–1:52 — Resolution

**Screen:** Resolved panel, community-health update, audit timeline.

**Narration:** “The seeded observation reports no renewed conflict. TEND closes the case, records that repair held, and prepares a positive prompt. AutoMod keeps a server clean. TEND helps keep a community healthy.”
